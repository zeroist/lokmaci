# Olgun Lokma · Bünyamin Usta

Türkçe, mobil uyumlu, bağımlılık gerektirmeyen tanıtım sitesi. Telefon ve WhatsApp: 0544 852 34 94.

## Yerel çalışma

Bu görev zaten yalıtılmış bir ortamda çalışır; mevcut `/workspace/lokmaci` deposunu kullanın, ayrıca Git worktree oluşturmayın.

```sh
cd /workspace/lokmaci
python -m http.server 8000 --bind 127.0.0.1
```

## Ücretsiz yayın

Herkese açık bir GitHub deposunda GitHub Pages ücretsizdir. Dosyaları `main` dalına gönderin. GitHub deposunda **Settings → Pages → Build and deployment → Source → GitHub Actions** seçin. Dahil edilen Pages iş akışı siteyi yayımlar. Beklenen adres `https://zeroist.github.io/lokmaci/`; dağıtım başarıyla bitmeden bu adresin çalıştığı varsayılmamalıdır. Ücretli alan adı veya sunucu gerekmez.

Site form, analiz servisi, çerez veya üçüncü taraf yazı tipi kullanmaz. WhatsApp bağlantısı tıklanınca WhatsApp açılır. Hizmet bölgesi: İzmir Torbalı öncelikli; Tire, Bayındır, Selçuk, Menderes, Ödemiş, Buca ve Gaziemir. Fiyat ve hizmet saatleri teyit edilmediği için eklenmemiştir. Lokma, tavuklu pilav, aşure ve irmik helvası görselleri yapay zekâ ile oluşturulmuş temsili sunumlardır. Ortak görsel `assets/ikramlar-ai.png` dosyasındadır; her ürünün karesi CSS ile ayrı çerçevelenir. Kullanıcının gönderdiği fotoğraf yerel dosya olarak erişilebilir olmadığı için siteye eklenmemiştir.
